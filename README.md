# Dan Taylor Starter Theme

A custom WordPress theme that provides a starting point for building websites.

## Features

- Custom Gutenberg blocks for hero sections, image-and-text layouts, cards, FAQs, news, and carousels.
- Tailwind CSS for styling.
- Primary and footer navigation menus, custom logo, and featured image support.
- FAQ custom post type.
- Bundled Splide assets for carousels.

The custom blocks require the Advanced Custom Fields plugin.

## Getting started

Install the development dependencies and build the theme stylesheet:

```sh
npm install
npm run build:style
```

To rebuild the stylesheet automatically while developing:

```sh
npm run watch:style
```
